# Lokal Music Player — Initial Project Setup

## Create Expo React Native App

```bash
npx create-expo-app lokal-music-player -t expo-template-blank-typescript
```

Move into the project directory:

```bash
cd lokal-music-player
```

---

# Install State Management & Networking

```bash
npm install zustand axios
```

### Packages

* **Zustand** → Lightweight global state management
* **Axios** → API requests and data fetching

---

# Install React Navigation

```bash
npm install @react-navigation/native
npm install @react-navigation/native-stack
```

---

# Install Expo & React Native Dependencies

```bash
npx expo install react-native-screens
npx expo install react-native-safe-area-context
npx expo install react-native-gesture-handler
npx expo install react-native-reanimated
```

### Packages

* **react-native-screens** → Optimized screen rendering
* **react-native-safe-area-context** → Safe area handling
* **react-native-gesture-handler** → Gesture support
* **react-native-reanimated** → High-performance animations

---

# Install Audio & Media

```bash
npx expo install expo-audio
npx expo install expo-file-system
```

### Packages

* **expo-audio** → Music playback engine
* **expo-file-system** → Downloading and storing offline music

---

# Install UI Dependencies

```bash
npx expo install expo-linear-gradient
npx expo install expo-status-bar
npx expo install @expo/vector-icons
```

### Packages

* **expo-linear-gradient** → Gradient backgrounds
* **expo-status-bar** → Status bar customization
* **@expo/vector-icons** → Ionicons and icon packs

---

# Install Storage & Queue Management

```bash
npm install react-native-mmkv
npm install react-native-nitro-modules
npm install react-native-draggable-flatlist
```

### Packages

* **react-native-mmkv** → Ultra-fast local storage
* **react-native-nitro-modules** → Required by MMKV
* **react-native-draggable-flatlist** → Drag-and-drop queue reordering

---

# EAS Build Setup

Install EAS CLI globally:

```bash
npm install -g eas-cli
```

Login to Expo Account:

```bash
eas login
```

Configure EAS Build:

```bash
eas build:configure
```

### Configuration Steps

