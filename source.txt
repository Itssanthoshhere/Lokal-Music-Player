# Lokal Music Player Source & Installations

This file outlines all the core dependencies and native modules installed in the project, and their sources.

## Core React Native & Expo
- `expo` (~56.0.8): The core Expo framework for building universal React apps.
- `react` (19.2.3): React library.
- `react-native` (0.85.3): React Native framework.

## Audio & Media
- `expo-audio` (~56.0.11): Powers the audio playback engine, providing background audio, seeking, and status updates.

## File System & Storage
- `expo-file-system` (~56.0.7): Handles the native file system access for downloading and saving offline MP3s.
- `react-native-mmkv` (^4.3.1): High-performance, synchronous key-value storage used to persist Zustand state (favorites, queue, downloads).
- `react-native-nitro-modules` (^0.35.9): Dependency required by MMKV for ultra-fast C++ native module access.

## State Management & Networking
- `zustand` (^5.0.14): A small, fast, and scalable bearbones state-management solution used for the global `playerStore`.
- `axios` (^1.17.0): Promise based HTTP client used to interface with the JioSaavn music API.

## Navigation
- `@react-navigation/native` (^7.2.5): Core routing and navigation wrapper.
- `@react-navigation/native-stack` (^7.16.0): Native stack navigator for screen transitions (like Player and Queue modals).
- `react-native-screens` (4.25.2): Provides native navigation primitives.

## UI & Interactions
- `@expo/vector-icons` (^15.0.2): Pre-packaged icon sets (Ionicons) used throughout the app.
- `expo-linear-gradient` (~56.0.4): Provides smooth gradient backgrounds (used in Player Screen).
- `expo-status-bar` (~56.0.4): Controls the app status bar style.
- `react-native-draggable-flatlist` (^4.0.3): Powers the drag-and-drop reordering functionality in the Queue screen.
- `react-native-gesture-handler` (~2.31.1): Required by draggable flatlist and navigation for fluid touch interactions.
- `react-native-reanimated` (4.3.1): Used for complex animations and transitions.
- `react-native-safe-area-context` (~5.7.0): Handles safe area insets (notches, dynamic islands, home indicators).

## Installation Details
If spinning this project up from scratch, these can be installed via:
`npx expo install expo-audio expo-file-system expo-linear-gradient expo-status-bar @expo/vector-icons react-native-safe-area-context react-native-screens react-native-gesture-handler react-native-reanimated`

`npm install zustand axios react-native-mmkv react-native-draggable-flatlist @react-navigation/native @react-navigation/native-stack react-native-nitro-modules`
